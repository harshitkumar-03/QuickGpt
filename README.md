# QuickGPT 🚀
An intelligent AI Assistant powered by Google Gemini.

## Features
- 🤖 AI Text Chat
- 🖼️ AI Image Generation
- 💳 Credits System (Stripe)
- 🌙 Dark Mode
- 🔐 JWT Authentication
- 📁 Chat History

## Tech Stack
**Frontend:** React, Vite, Tailwind CSS

**Backend:** Node.js, Express, MongoDB, Stripe, ImageKit, OpenRouter API

## Live Demo
- Frontend: https://quickgpt-omega.vercel.app
- Backend: https://quickgpt-backend-phi.vercel.app

## Environment Variables
### Server
- MONGODB_URI
- JWT_SECRET
- OPENROUTER_API_KEY
- GEMINI_API_KEY
- IMAGEKIT_PUBLIC_KEY
- IMAGEKIT_PRIVATE_KEY
- IMAGEKIT_URL_ENDPOINT
- STRIPE_SECRET_KEY
- STRIPE_WEBHOOK_SECRET

### Client
- VITE_SERVER_URL
